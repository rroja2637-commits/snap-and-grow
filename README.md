\# 🌱 Snap \& Grow – AI Plant Health Assistant



Snap \& Grow is an AI-powered plant health assistant that analyzes a plant or leaf image and provides simple, practical plant-care guidance.



\## 🌿 Features



\- 📸 Upload a plant or leaf image

\- 🤖 AI-based plant identification when possible

\- 🔍 Analysis of visible signs on the plant

\- ⚠️ Possible plant-health issues

\- 🌱 Basic and safe care recommendations

\- 👀 Things to monitor over the next few days

\- 🛡️ Avoids claiming a definite disease diagnosis from an image alone



\## 🛠️ Technologies Used



\- Python

\- Streamlit

\- Google Gemini API

\- Google GenAI Python SDK
